## 📖 Sobre este Repositório

> Repositório de estudos do curso **Mensageria com Java: RabbitMQ e Kafka** da Alura.
> Aqui você encontrará anotações, implementações práticas e projetos desenvolvidos ao longo do curso, cobrindo desde os fundamentos de mensageria assíncrona até padrões avançados como Saga Pattern e Schema Registry com Avro.

---

## 🎯 Objetivos de Aprendizado

```
✅ Padrões de comunicação: Fire and Forget, PubSub e mais
✅ RabbitMQ via Docker integrado ao Quarkus
✅ Produtores e consumidores reativos com filas, exchanges e DLQ
✅ Kafka: tópicos, partições e offsets
✅ Saga Pattern para transações distribuídas
✅ Schema Registry + Avro para validação de contratos
```

## 📌 Conceitos-Chave Estudados

```
🔹 Fire and Forget       — Envio sem esperar confirmação
🔹 PubSub Pattern        — Publicação e assinatura de eventos
🔹 Dead Letter Queue     — Tratamento de mensagens com falha
🔹 Exchanges & Bindings  — Roteamento de mensagens no RabbitMQ
🔹 Tópicos & Partições   — Paralelismo e escalabilidade no Kafka
🔹 Consumer Groups       — Balanceamento de carga de consumidores
🔹 Schema Registry       — Governança e contratos de mensagens
🔹 Apache Avro           — Serialização binária eficiente
🔹 Saga Pattern          — Consistência em transações distribuídas
```
